# Patch Adams 1.2.1

Pasted write-ups split on any heading, and the findings list reads as
text.

## Findings

- **Any heading is a category.** A line that opens with a short label
  and a colon — `Bad Tests: …` — starts a finding. A known category by
  name or slug keeps its name; any other label becomes a category of its
  own and joins the session's list. File references, links, patch names
  and sentences are left alone. (#42)
- **Rows show only their text.** A finding that is not selected shows
  its text alone; the label, severity, category and icons appear when
  you select it. (#43)
