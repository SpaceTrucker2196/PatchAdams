# Patch Adams 1.1.2

Findings read and edit like a document, and New Session always comes
back to the opening screen.

## Findings

- **Click a reference in the text.** Each reference written in a
  finding, like `core/queue.go L20-L28`, is a link: a click jumps to the
  lines and opens the patch they are in, as the reference buttons do.
  (#33)
- **See where a reference came from.** Clicking a reference — button or
  link — washes its words in the finding text amber. (#31)
- **Spelling and editing.** Finding text has the system's spelling and
  grammar checking as you type, the Find bar (⌘F), undo, and the usual
  right-click tools; autocorrect and smart quotes follow your System
  Settings. (#34)
- **Full text everywhere.** Findings you have not opened show their whole
  text, not a two-line preview; a click opens one for editing. (#34)

## Fixes

- **New Session** always shows the opening screen, with nothing left
  over from the last session. Some launches came up with no window; the
  app now opens its window if it is missing, and closing the window
  quits the app. (#32)
- A speed test no longer fails on a busy Mac: it measures CPU time, not
  the wall clock.
