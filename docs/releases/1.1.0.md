# Patch Adams 1.1.0

Findings you can paste, sessions in one file, and a window that scales
from a laptop to a 5K display.

## Findings

- **Paste a finding.** Click **+** in the findings sidebar, paste the
  text, and pick the category. The app reads the evidence from it:
  `catalog.go L106-L110`, `main.go L349, L699-L702`, `L 759:L 793`,
  `-L40` for removed lines. "Implementation A" picks the patch. (#17)
- **Cross-patch evidence.** `(B main.go L640)` puts that evidence in
  patch B, for findings that compare implementations. (#28)
- **Missing evidence is flagged.** Text with no file and line numbers
  in the patch turns red, with a short guide to the format under it.
  References not in the patch show red. (#25)
- **Click a finding to focus it.** Its lines turn amber in every patch
  it cites, the other patches fold to thin strips, and the code scrolls
  to it. *Close Finding* brings everything back. (#19, #23)
- **Navigate by reference.** Each reference is a button that jumps to
  its lines and opens the patch they are in. (#24)
- **Edit in place.** The open finding shows its full text at the code's
  size, editable, with the category, severity and note. Edit and delete
  buttons on every finding; delete asks first. (#20, #21, #26)

## Sessions

- **One file.** ⌘S saves a single `.patchadam` file holding the session
  and every patch. Mail it, archive it, reopen it with ⌥⌘O. Sessions
  saved as folders by 1.0 still open. (#27, DECISIONS.md D11)
- **Task header.** A title for the task (e.g. *Implementation
  comparison 103*), the request, free task info and instructions, all
  saved with the session. (#27)

## Getting started

- **A first-run guide** explains loading patches. (#22)
- **Patches load in order A, B, C, D.** The opening screen shows the
  four slots, arrows to reorder, and a *Confirm Order* step before the
  review starts. (#22)
- **Only have the patches?** The opening screen offers *Build Base
  from Patches* plainly, and Confirm builds it for you if no base is
  chosen. (#22)

## Display

- **Interface and content scale.** Two − / + pairs in the status bar:
  *Interface* (80–200%: every panel, header and footer) and *Code*
  (9–24 pt). Also ⌥⌘= / ⌥⌘− / ⌥⌘0 and Settings. (#29)
- Line numbers now match the code's size. (#16)
- Faint greenbar stripes on alternate lines. (#18)
- The findings sidebar is a quarter of the window; the add-patch slot
  is a thin column with an icon.
