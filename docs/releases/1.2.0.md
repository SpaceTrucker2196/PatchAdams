# Patch Adams 1.2.0

The app tells you when a new release is out, every prose field checks
your spelling, and a pasted write-up with category headings becomes one
finding per heading.

## Updates

- **New release reminder.** Once a day the app asks GitHub for the
  latest release. When it is newer than the one you run, a banner under
  the toolbar offers Download and Later. Settings → Updates turns the
  check off. This is the app's one network call; it carries nothing
  about your work. (#35)

## Findings

- **Spelling everywhere.** The title, the correctness note, the
  rationale, the task header fields and the paste box now check
  spelling and grammar as you type, like the finding text. (#36)
- **References on a light wash.** A reference in a finding's text no
  longer has an underline, which read as a spelling error; it sits on a
  slightly lighter ground. The clicked one is still amber. (#37)
- **Category headings.** The thirteen slop categories carry their slug
  and a one-line summary, shown under the picker. In a pasted write-up,
  a line that opens with a category name or slug and a colon —
  `Unneeded backwards compatibility: brew.go L10 …` — names the category
  and starts a finding; several headings, several findings. (#38)
- **Chips by category.** Under an open finding, the reference chips sit
  under the category heading each is written beneath. (#39)
- **Copy a finding's text.** A copy icon on every finding row puts its
  text on the clipboard. (#41)

## Task header

- **Full size.** Click the heading of Request, Task info or
  Instructions to open it over the whole view below the header, editable;
  Done or Escape closes it. (#40)
