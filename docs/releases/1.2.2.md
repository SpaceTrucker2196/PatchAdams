# Patch Adams 1.2.2

Patch pickers start in Downloads, session panels in your project
directory, and the selected finding is a darker amber.

## Files

- **Patches from Downloads.** Add Patches and the replace-a-patch click
  open in ~/Downloads every time. (#44)
- **The project directory.** The folder you last saved or opened a
  session in is remembered; Save Session, Open Session and the exports
  start there, whatever the patch pickers were doing. (#46)

## Findings

- **Darker wash.** The selected finding's amber, in the sidebar and on
  its lines in the code, is a darker brown. A clicked reference keeps
  the brighter amber. (#45)
