# Patch Adams 1.1.1

A fix for findings whose evidence is in a file that shares its name
with another file.

## Fixes

- **Evidence in same-named files.** A stored reference keeps only the
  file name, such as `B brew.go L33:L40`. With two files of that name
  (`api/dto/brew.go`, `api/handler/brew.go`), the app could pick the
  wrong one: the reference button said the lines were not in the
  patch, the patch did not open, and the lines were not highlighted.
  The app now tries the exact path, then the file on screen, then the
  others, and takes the one that has the lines. (#30)
